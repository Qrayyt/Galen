# Galen website
Страница установки получает актуальный релиз из `/downloads/latest.json` на galen.galenite.org. Серверный `scripts/galen/sync_public_release.py` зеркалирует только опубликованные проверенные Windows-сборки, сохраняя приватность GitHub. Никаких токенов на клиенте. Mac и Linux пока недоступны. При локальном тестировании используется HTTPS-публичный манифест; сайт должен быть запущен на сервере для полного сценария.
