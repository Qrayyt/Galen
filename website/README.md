# Galen website
The installation page reads the same-origin Windows and macOS release manifests under /downloads/. The server runs scripts/galen/sync_public_release.py to verify GitHub release metadata and small SHA-256 files, then publishes only metadata and checksum files. Include scripts/galen/nginx-release-redirect.conf in the HTTPS virtual host; the /downloads/ fallback must not use ^~. Installer requests redirect directly to public GitHub Releases, including legacy URLs, so no installer binary needs local storage. Existing installed clients keep the same feed URLs and checksum validation. No GitHub token is required. Linux remains unavailable until a verified Linux release is published.
