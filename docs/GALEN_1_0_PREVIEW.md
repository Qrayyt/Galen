# Galen 1.0 Preview — Windows

Первый установочный выпуск Galen на новой платформе.

### Возможности
- Десктопный интерфейс Dodaios в фирменной версии Galen от Galenite.
- Русский язык интерфейса по умолчанию; ключевые разделы переведены, дополнительные экраны пока могут показывать английские строки.
- Разговорные режимы, подключаемые модели и Codex CLI, API/MCP, Computer Use и агентное рабочее пространство исходной платформы.
- Новый необязательный HUD из компонентов OpenDex (URL внутри приложения: `?view=galen-hud`).
- Дополнительные инструменты Windows Kaizumi и управления звуком Elissa, доступные через встроенные разрешения.
- Отдельный экспериментальный движок OpenRealtime в бинарном наборе Windows, если компиляция прошла успешно.

### Перед установкой
- Сборка экспериментальная, установщик может быть неподписан.
- Сохраняйте резервные копии рабочих файлов, прежде чем давать ИИ возможность изменять их.
- Вход ChatGPT в официальном Codex CLI и доступ к OpenRouter/API — разные механизмы.
- Авторизация и реальные операции проверяются на локальной машине пользователя.

### Благодарности
Galen развивается Galenite на основе открытого кода [Dodaios](https://github.com/Dodaios/Dodaios) (Apache-2.0), с исходными реализациями и разработками [OpenDex](https://github.com/wassgha/opendex), [Kaizumi](https://github.com/MusayevDoniyor/kaizumi), [Elissa](https://github.com/inginddie/elissa), [OpenRealtime](https://github.com/bojieli/OpenRealtime) (MIT). Подробности лицензий — в репозитории.

### Совместимость
Windows 11 x64. Linux/macOS требуют отдельной сборки и проверки, которые не входят в этот установщик.
