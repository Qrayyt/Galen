# Galen 1.0 Preview 4

Техническое обновление канала доставки Galen для Windows x64. Исходный репозиторий остаётся приватным; установщики зеркалируются на galen.galenite.org после сверки SHA-256. Добавлены автоматическая повторная проверка обновлений и заметная панель загрузки. Существующий механизм безопасной установки, сохранения данных и перезапуска сохранён. Это ещё не завершение функционального этапа Preview 4. Реальное обновление с предыдущей версии на Windows требует проверки.
