# Galen 1.0 Preview 6 · Galenite

- Единая история Chat и Work, отдельные сессии, поиск и проекты.
- Изоляция контекста и автоматической памяти, сохранение истории при переносе голосовых чатов.
- Generative UI: интерактивные карточки, таблицы, графики и другие безопасные нативные компоненты.
- GLNT Marketplace: каталог, проверяемые расширения с GitHub, публикация по ссылке, модерация.
- Установщики Windows x64, macOS Apple Silicon и macOS Intel.

Сборки из одного исходного коммита: da7a30e43dd87fbb429ca2df5854bb66ebbd7012.
CI: 46 базовых и 256 расширенных backend-тестов, frontend, проверка установки/переустановки Windows и изолированный UI smoke успешно.
Preview-версия: ручная проверка macOS и полный цикл публикации расширения через реальный GitHub-аккаунт ещё не завершены. macOS может потребовать подтверждения запуска в настройках безопасности, если сборка не нотарифицирована Apple.
