# Galen 0.5.0-beta.1

Тестовая сборка для проверки на реальном ПК. Это не завершённый стабильный v0.5.0.

- Исправлено склеивание слов и потеря переносов между фрагментами ответа.
- Windows-команды выполняются через PowerShell.
- Добавлены инструменты чтения и создания UTF-8 файлов в выбранной рабочей папке, с подтверждением и проверкой записи. Существующие файлы инструмент создания не перезаписывает.
- Новая управляемая интеграция ComfyUI и автообновление в эту сборку не входят.

Закрой Galen и установи Windows Setup поверх предыдущей версии. Идентификатор приложения сохранён; до установки рекомендуется резервная копия профиля приложения. Переход на реальном ПК ещё не проверен.

В настройках укажи существующую отдельную рабочую папку. Попроси создать в ней hello.ps1, вывести «Привет мир» и запустить его. Подтверди создание, затем запуск. Проверь файл в папке и результат команды. Проверь обычный текст, таблицу и блок кода — пробелы и переносы должны сохраниться.

Разработка приостановлена до обратной связи пользователя. Долгие процессы, карточки артефактов и полный редактор файлов остаются в плане будущей версии.
