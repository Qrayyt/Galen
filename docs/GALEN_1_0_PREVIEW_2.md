# Galen 1.0 Preview 2

Вторая предварительная версия Galen 1.0 сосредоточена на русском интерфейсе,
новом фирменном знаке и нормальном обновлении приложения без потери настроек.

## Что изменилось

- Русская локализация теперь покрывает основной интерфейс и все лениво
  загружаемые разделы: подключение, провайдеры, компьютеры, общество агентов,
  редакторы, память, голос, приватность, маркетплейс и другие экраны.
- Новый чёрный геометрический знак Galen используется в окне, загрузочном
  экране, браузерной иконке, PWA, панели задач, ярлыках и Windows-установщике.
- При запуске Galen проверяет стабильные и Preview-релизы. Если доступна новая
  версия, приложение само открывает панель обновления с описанием и кнопкой
  «Обновить и перезапустить».
- Установщик скачивается с индикатором прогресса и устанавливается только после
  проверки SHA-256. После тихого обновления Galen запускается снова.
- Все пользовательские данные остаются в `%LOCALAPPDATA%\GalenData`. Обновление
  заменяет только файлы программы и не перезаписывает настройки, ключи, память,
  навыки, историю и логи.

## Важное про переход с Preview 1

Preview 1 ещё не умела видеть предварительные GitHub-релизы и ожидала старые
имена установщиков Dodaios. Поэтому переход с Preview 1 на Preview 2 нужно один
раз выполнить обычным установщиком поверх текущей версии. Начиная с Preview 2,
следующие обновления устанавливаются из самого Galen.

Это всё ещё Preview, а не стабильная Galen 1.0. Перед публикацией стабильной
версии будут отдельно проверены Windows UI, голос, действия на компьютере и
обновление между двумя реальными установщиками.
