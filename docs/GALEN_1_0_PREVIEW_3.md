# Galen 1.0 Preview 3

Третья предварительная версия Galen посвящена завершению основных элементов фирменного интерфейса. Это тестовый выпуск Windows 11 x64, не стабильная версия 1.0.

## Изменения

- Фирменный знак Galen в векторных элементах интерфейса; голосовой HUD адаптирован к светлой и тёмной темам и системной локализации.
- Исправлены обнаруженные ошибки русского перевода, подписи статусов, экран запуска и восстановления интерфейса, меню трея и тестовое уведомление.
- Экспорт статистики использует бренд Galen и имя файла galen-stats.png.
- Сторонний каталог расширений Dodaios обозначен явно. Существующие плагины и настройки не менялись.
- Обновлены фирменные рекомендации и стандартная голосовая идентичность приложения без изменения пользовательского имени.

## Установка и проверка

Сборка предназначена для проверки на Windows 11 x64. Preview 2 должна обнаружить новую версию через встроенное обновление; обновление между реальными установщиками, визуальный аудит всех экранов и работа на физическом ПК ещё требуют подтверждения. Сохраните резервную копию важных данных. Установщик может быть неподписан; сверяйте SHA-256.

Новые функции, собственный Marketplace, новые движки речи и Linux/macOS не входят в этот выпуск. Следующий этап — проверка существующих рабочих сценариев.
