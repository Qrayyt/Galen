# Galen 1.0 Preview 5

Windows x64. Новый интерфейс установщика Galen на WPF с существующим движком Inno Setup, реальным прогрессом и обработкой ошибок. Обновления интерфейса приложения и брендинга. Поставка через проверяемый SHA-256 установщик и публичный канал galen.galenite.org. Проверка обновления с Preview 4 на реальном компьютере требуется отдельно. macOS и Linux в этот релиз не входят.

macOS: отдельные DMG для Apple Silicon и Intel. Preview распространяется с ad-hoc подписью без нотарификации Apple; при первом запуске возможно предупреждение Gatekeeper. Целостность файлов проверяется SHA-256. Linux в этот релиз не входит.
