## Что умеет Galen 0.4.2

- Локальный агентный цикл на Ollama с вызовом инструментов.
- Актуальный веб-поиск и чтение страниц без API-ключа.
- Терминал в стиле coding agents: модель предлагает команду, приложение показывает папку и причину, пользователь отдельно подтверждает запуск.
- Три настоящих режима: **Лёгкий**, **Средний**, **Тяжёлый** — разный thinking, контекст и лимит инструментальных шагов.
- **Galen Core Prompt v2**: единый developer prompt задаёт качество ответа, проверку фактов, работу с инструментами, Markdown, защиту от prompt injection и скрытое reasoning. В настройках есть отдельное поле для постоянных пользовательских инструкций.
- Внутренние рассуждения отделены от ответа. Во время работы видны короткие статусы, а после — свёрнутый блок «Думал N секунд», который можно раскрыть.
- Несколько чатов с локальной историей.
- Долговременная память между чатами: автоматическое извлечение полезных фактов, ручное добавление, редактирование, отключение и полная очистка.
- Вложения: изображения, PDF, DOCX, TXT, Markdown, CSV, JSON и исходный код.
- Анализ изображений через установленную vision-модель, например **qwen3-vl:8b** или **gemma3:4b**.
- Голосовой ввод, отдельный непрерывный голосовой режим и естественная русская нейронная озвучка. Полностью офлайн-системный голос можно выбрать вручную в настройках.
- Model Studio с категориями «Текст», «Vision», «Изображения», «Видео» и «Голос», Galen score и процентом совместимости с компьютером.
- В каждой категории есть отдельная линейка **Dark Models**: быстрый, оптимальный для компьютера и более медленный качественный варианты. Abliterated/uncensored текст и vision, локальные NSFW-checkpoints для ComfyUI и голосовые пресеты включаются только вручную и не подменяют обычную рекомендацию.
- Galen автоматически проверяет GitHub Releases каждые 5 минут и предлагает тихое обновление прямо в приложении с прогрессом загрузки.
- Модели Ollama загружаются прямо в приложении с реальным progress bar. Для изображений и видео Model Studio подключает ComfyUI и ведёт к официальным шаблонам, которые устанавливают нужные веса вместе с workflow.
- Анализ CPU, RAM, GPU, VRAM, ОС и автоматический подбор модели.
- Светлый монохромный интерфейс с GPU-friendly анимациями только через transform и opacity.

## Рекомендуемая модель для мощного ПК

Для Ryzen 9 5950X, RTX 5060 Ti 16 ГБ и 32 ГБ RAM Galen рекомендует:

~~~text
qwen3.5:9b
~~~

Это лучший баланс нового поколения, качества, русского языка, vision и скорости для 16 ГБ VRAM. Если нужен более тяжёлый текстовый анализ, можно выбрать **qwen3:14b**. Для отдельного анализа изображений подходит **qwen3-vl:8b**: Galen автоматически переключится на установленную vision-модель, когда в сообщении есть картинка.

## Установка на Windows 11

1. Установи Ollama в обычном PowerShell:

~~~powershell
irm https://ollama.com/install.ps1 | iex
~~~

2. Открой [последний релиз](https://github.com/Qrayyt/Galen/releases/latest).
3. Скачай **Galen_*_x64-setup.exe** и установи поверх предыдущей версии.
4. Если SmartScreen покажет предупреждение для неподписанной сборки: «Подробнее» → «Выполнить в любом случае».

Модели Ollama не удаляются при обновлении Galen.

> Поскольку исходный репозиторий Galen сейчас приватный, встроенная проверка обновлений использует авторизованный GitHub CLI (`gh`). Токены внутрь приложения не зашиваются.

## Первый запуск

1. Открой раздел «Модели».
2. Нажми «Скачать» у рекомендованной модели.
3. Дождись 100% — только после полной загрузки модель станет активной.
4. Создай новый чат.
5. Проверь веб запросом «Что произошло сегодня в мире ИИ?».
6. Проверь терминал запросом «Покажи характеристики этого компьютера через консоль».

Команды терминала никогда не запускаются молча: перед выполнением появляется отдельная карточка подтверждения.

## Голос на Windows

Galen сначала использует встроенное распознавание Windows через System.Speech, затем Web Speech как запасной вариант. Для русского ввода должен быть установлен русский речевой пакет Windows. По умолчанию ответы озвучивает естественный Microsoft Neural Voice без API-ключа; в настройках можно включить полностью офлайн-системный голос.

## Приватность

Локально остаются:

- история чатов;
- память о пользователе;
- текст извлечённых документов;
- изображения;
- запросы к модели;
- вывод команд терминала.

Когда включён веб, наружу уходят поисковые запросы и URL страниц, которые агент решил прочитать. При нейронной озвучке Microsoft получает только текст озвучиваемого ответа. Веб, терминал, память и сетевую озвучку можно отключить независимо.

## Безопасность инструментов

- локальные и приватные IP блокируются для веб-инструмента;
- разрешены только HTTP/HTTPS URL;
- число redirect ограничено;
- вывод команды ограничен по размеру;
- команда останавливается по таймауту;
- каждая команда требует явного разрешения.
