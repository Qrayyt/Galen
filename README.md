# Galen

Личный десктопный AI-ассистент на реальной кодовой базе [Dodaios](https://github.com/Dodaios/Dodaios).

**Ветка разработки:** `feat/galen-1.0-dodaios`

Это исходники Dodaios, перенесённые в Galen, а не самостоятельная переписанная реализация. Основной интерфейс, голос, агентное ядро, подключение инструментов, Computer Use и авторизация через поддерживаемые официальные CLI сохранены из оригинала.

Следующие изменения: русская локализация, идентичность Galen, подключение дополнительных компонентов после проверки совместимости. Пока сборка и запуск перенесённой версии не подтверждены.
