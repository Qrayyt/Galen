# Galen

## Ассистент, который не ограничивается разговором

Скажи «Гален, открой Telegram и проверь рабочие сообщения» — ассистент выбирает доступные инструменты, выполняет задачу и объясняет результат. Для действий на компьютере использует инструменты операционной системы, браузер и Computer Use. Для сервисов — плагины, подключённые API, MCP и официальные CLI. Команды, требующие подтверждения, отображаются отдельно.

## Установка

### Windows 11

1. Откройте **[Releases](https://github.com/Qrayyt/Galen/releases)** и выберите последнюю проверенную сборку Galen.
2. Загрузите установщик Windows, если он доступен для выбранного релиза.
3. После установки выберите имя ассистента, способ общения и модель или поддерживаемый CLI.

> Установщики могут быть не подписаны сертификатом. Сверяйте издателя, SHA-256 и опубликованные исходники перед установкой. Разработка Galen 1.0 ведётся в [отдельной ветке](https://github.com/Qrayyt/Galen/tree/feat/galen-1.0-dodaios).

### Сборка из исходников

Требуются Python 3.12, Node.js 22 и инструменты соответствующей платформы.

```bash
git clone https://github.com/Qrayyt/Galen.git
cd Galen
git switch feat/galen-1.0-dodaios
python -m pip install -e ".[desktop,dev]"
cd dodaios/ui/web/frontend
npm ci
npm run build
cd ../../../..
python -m dodaios
```

**Windows** — для установленного Python может понадобиться запуск `py -3.12 -m pip`. Конкретная сборка Windows-установщика использует PyInstaller и Inno Setup 6, см. `packaging/windows/build.ps1`.

## Подключение моделей и сервисов

Galen **не требует отдельного аккаунта Galenite** для локального использования. В настройках можно выбрать поддерживаемого провайдера, подключить API-ключ либо войти через официальный CLI-клиент, если этот способ поддерживается соответствующей интеграцией.

- **ChatGPT / Codex** — вход через официальный Codex CLI с использованием разрешённого способа авторизации.
- **OpenRouter** — подключение через API-ключ и выбор доступных моделей.
- **MCP и API** — подключение разрешённых внешних инструментов, сервисов и интеграций.
- **Computer Use** — отдельные настройки модели, разрешений и видимости рабочего стола.

Подписка ChatGPT и вход в Codex CLI **не предоставляют автоматически** доступ к OpenRouter или OpenAI API. Использование сторонних моделей и функций зависит от условий провайдеров.

## Развитие Galen

Galenite развивает **персональное desktop AI-пространство**: собственную айдентику, русскую локализацию, соединение речи с действиями и расширяемый набор компьютерных инструментов. Основная система построена на архитектуре Dodaios; развитие Galen ведётся с сохранением её возможностей и совместимости.

**Текущий статус:** активная разработка Galen 1.0. Базовый исходный код Dodaios перенесён, запущена русская локализация. Полный перевод, единая идентичность приложения, отдельные голосовые и HUD-модули и нативные пакеты проверяются поэтапно. Проверки, выполненные не полностью, не считаются готовыми функциями.
