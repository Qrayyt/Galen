# OpenRealtime companion (experimental)

This directory contains the pinned upstream Go runtime and is compiled as a separately launched companion. It is NOT the default Galen voice engine.
The native Dodaios Realtime/Pipeline engines remain the supported default.
Run `go build -o ../bin/openrealtime.exe ./cmd/openrealtime` in source/ on Windows.
Configuration and API credentials follow upstream OpenRealtime documentation.
